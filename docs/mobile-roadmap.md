# STEEZE Mobile App Roadmap

**Last Updated:** June 1, 2026
**Version:** 1.0

## Current State: PWA

STEEZE currently operates as a Progressive Web App installable on iOS and Android.

## Native App Strategy

### Phase 1: Foundation (Q3-Q4 2026)
- React Native project setup with TypeScript
- Core navigation and authentication
- Feed and profile views

### Phase 2: Feature Parity (Q1 2027)
- Content upload (photos, videos, audio)
- Subscription purchases (IAP)
- Messaging and notifications
- Wallet and payouts

### Phase 3: Native Enhancements (Q2 2027)
- Biometric authentication (Face ID, Fingerprint)
- Camera and audio recording
- Offline mode and widgets

### Phase 4: Store Submission (Q3 2027)
- Beta testing (TestFlight + Internal)
- App Store and Play Store submission
- Public launch

## Technology Stack
- React Native + TypeScript
- Zustand (state management)
- React Navigation
- Paystack SDK + IAP

## Success Metrics
- App Store rating: 4.5+ stars
- Crash-free rate: 99.5%+
- DAU: 50% of web DAU

## Budget: R1.3M - R1.95M
