# STEEZE Data Retention Policy

**Last Updated:** June 1, 2026
**Version:** 1.0
**Applies to:** All STEEZE users (Creators and Vibes)

---

## Overview

STEEZE is committed to protecting user data and complying with applicable privacy laws including POPIA (South Africa) and GDPR (Europe). This policy outlines how long we retain different types of user data and the processes for data deletion.

---

## Data Retention Periods

| Data Type | Retention Period | Justification |
|-----------|-----------------|---------------|
| User account data (email, name, profile) | Until account deletion + 30 days | Allows account reactivation |
| Payment transaction records | 7 years | Tax and audit compliance |
| Subscription records | 7 years | Financial audit trail |
| User-generated content (posts, comments) | Until user deletes or account deletion | User control over content |
| Private messages | 30 days after deletion | User privacy |
| Login history | 90 days | Security monitoring |
| IP address logs | 90 days | Security and fraud prevention |
| System audit logs | 7 years | Legal and compliance requirements |
| Email verification records | Until account deletion | Account security |
| Withdrawal/payout records | 7 years | Financial audit trail |
| Support tickets | 2 years | Customer service continuity |

---

## Data Deletion Process

### User-Initiated Deletion

1. User requests account deletion via Settings → Delete Account
2. Account enters 30-day grace period
3. User can cancel deletion within 30 days
4. After 30 days, account and all associated data are permanently deleted
5. User receives confirmation email upon completion

### Automatic Deletion

- Expired sessions: Deleted after 7 days of inactivity
- Unverified email addresses: Deleted after 30 days
- Abandoned payment attempts: Deleted after 24 hours

### Backup Retention

- Database backups: Retained for 30 days
- Backups are automatically rotated
- Deleted user data is removed from backups after the retention period

## User Rights

Under applicable privacy laws, STEEZE users have the following rights:

| Right | Description | How to Exercise |
|-------|-------------|-----------------|
| Right to Access | Request copy of your data | Settings → Data Export |
| Right to Rectification | Correct inaccurate data | Settings → Profile |
| Right to Deletion | Request account deletion | Settings → Delete Account |
| Right to Portability | Download data in machine-readable format | Settings → Data Export |
| Right to Object | Object to data processing | Contact privacy@steeze.com |
