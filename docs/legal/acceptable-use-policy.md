# STEEZE Acceptable Use Policy (AUP)

**Last Updated:** June 1, 2026
**Version:** 1.0

## 1. Introduction

STEEZE is a verified entertainment platform for creators and fans. This Acceptable Use Policy outlines what is and is not permitted on the platform.

## 2. Prohibited Content

The following content is strictly prohibited on STEEZE:

| Category | Examples |
|----------|----------|
| **Illegal content** | Any content violating South African or international law |
| **Hate speech** | Content attacking individuals or groups based on race, religion, gender, sexual orientation, disability |
| **Harassment** | Bullying, threats, doxxing, repeated unwanted contact |
| **Violence** | Graphic violence, threats of violence, glorification of violence |
| **Nudity/Sexual content** | Explicit sexual content, pornography, sexual solicitation |
| **Copyright infringement** | Unauthorized use of copyrighted music, videos, images |
| **Fraud/Scams** | Fake accounts, impersonation, phishing, deceptive practices |
| **Spam** | Repetitive content, unwanted promotions, bot activity |
| **Political content** | Political propaganda, election interference, government criticism |
| **News content** | STEEZE is for entertainment only — no news reporting |
| **Misinformation** | False or misleading information |

## 3. Prohibited Activities

Users may not:

| Activity | Description |
|----------|-------------|
| **Impersonation** | Pretending to be another person, brand, or creator |
| **Evading bans** | Creating new accounts after being banned |
| **Automated access** | Using bots, scrapers, or automated tools without permission |
| **DDoS attacks** | Attempting to disrupt platform availability |
| **Security testing** | Attempting to bypass security measures without authorization |

## 4. Creator-Specific Rules

Creators must additionally comply with:

| Rule | Requirement |
|------|-------------|
| **Age verification** | Must be 18+ to become a creator |
| **ID verification** | Valid government ID required |
| **Original content** | All uploaded content must be original or properly licensed |
| **Accurate representation** | No misleading thumbnails or titles |

## 5. Enforcement

| Violation Level | Action |
|-----------------|--------|
| **First offense (minor)** | Warning + content removal |
| **Second offense** | Temporary suspension (7-30 days) |
| **Serious offense** | Permanent ban + account deletion |
| **Illegal activity** | Permanent ban + reported to authorities |

## 6. Appeals Process

Users may appeal enforcement actions by:

1. Emailing `appeals@steeze.com`
2. Providing the violation notice reference number
3. Explaining why the action should be reconsidered

**Response time:** Within 7 business days

## 7. Reporting Violations

To report a violation:

- **In-app:** Click the "Report" button on any post or profile
- **Email:** `abuse@steeze.com`
- **Form:** https://steeze.com/report

## 8. Contact

For questions about this policy:

**Email:** legal@steeze.com
